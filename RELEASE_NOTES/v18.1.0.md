# Fina v18.1.0

- Novo app **Fina Mobile** (Android) para lançar despesas do celular: pareia com o desktop por QR code na rede local, sem servidor externo, e sincroniza contas e categorias automaticamente.
- Tela "Sincronizar celular" no desktop agora usa uma porta fixa para a conexão com o app mobile, o que permite liberar o firewall uma única vez em vez de a cada sincronização (e libera sozinha em distros com firewalld, como openSUSE/Fedora).
